## What helped / misled

- **brief**: the one screen with fonts, colours, cap and the per-section rhythm at 1440 replaced the first spec read (tokens, body row, bands) — helped. It misled on section padding (`pad 0px` is the outer container) and said nothing about images beyond size.
- **--draft-new**: gave a lint-clean skeleton with every text and media URL in 1 s — helped (no generator); its rows needed the edits above — the shapes transfer, the row boundaries do not yet.
- **section marks** (`--sections` in measure-page → triage/spec/gate split): the 7-section split was consistent across the three tools from the second measure-page run — helped; the default selector and the missing guess cost a run.
- **--noise**: the 11.6 % reading was the right alarm (a composition) and the 0 % floor the right baseline — helped; it needed `--require` to be a wait, not a check.
- **gate's section tables / hottest band / pair Δy·loc**: the per-section Δh rows and the pair's cascade-vs-own column named every round's target (the +64 section-4 surplus, the reverse card's lost margin, the footer x offset) — helped most; "sections —" in the timing line (no `sections` run) and no printed per-width table from `sections.mjs` — the rows line did the job.
- **hover-diff** vs the frame sampler: every hover the sampler called dead, hover-diff read (bars, arrow) — as METHOD says; the compare's "0 ms" on a pseudo-element was new.
